## 所有 Bottom Sheet

逐项验证任务编辑、任务整理、长期计划、专注日程、提前结束、手机诱因确认、低能量、所有设置、专注复盘和专注回执：

- 把手可见且从把手下拉关闭。
- 内容在顶部时，从内容区域继续向下可拖动 Sheet。
- 内容未到顶部时，下拉只滚动内容，不误关 Sheet。
- 未达到距离/速度阈值时回弹。
- 遮罩、关闭按钮、Android 返回各只关闭最上层一次。

- 关闭后 TalkBack 焦点返回合理入口；减少动态不运行非必要循环。

## 核心链路

1. 创建任务输入标题后切后台并杀进程；重启必须恢复草稿。
2. 编辑任务输入后重复点保存、关闭和返回；正式任务只写一次，失败后输入保留。
3. 长按 1000ms 选中任务；同一手势和第二次触碰均可拖动；同象限位置和跨象限均持久化。
4. 拖动期间滚动页面、按返回、切后台；只退出当前层，任务 ID / 完成 / 成长事件不变化。
5. 开始、恢复、提前结束、正常结束专注；通知动作与 App 内动作同时触发不得重复结算。
6. 构造两次合计不足 60 秒的会话；界面显示“2 次 / 不足1分钟”，跨本地零点归到正确日期。
7. 创建、编辑、暂停、删除专注日程；拒绝/永久拒绝通知权限时有可理解状态和系统设置入口。
8. 备份导出、安全替换失败回滚、精确文本清除、防快速连点；不得出现备份合并执行入口。

## 无障碍和适配
